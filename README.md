# 🌐 Manjunath Shanmugari — Portfolio 

> A modern, interactive developer portfolio built with React featuring animations, chatbot, and AI integration.

---

## ✨ What's New in v2

- Typewriter animation in Hero — cycles through roles automatically  
- Animated particle network background with connected nodes  
- Scroll-triggered animations (fade + slide)  
- Glowing gradient borders on project cards (hover effect)  
- Skill bars that animate on scroll  

### 🤖 Chatbot Upgrades
- 🃏 Card-based responses (Projects, Skills, Contact, Resume)  
- ⚡ Quick Action buttons  
- 🖊️ Typing animation (character-by-character)  
- 🤖 AI Mode toggle (rule-based ↔ Claude AI)  
- Smooth bubble animations + auto-scroll  

### 🎨 UI Enhancements
- Orb glow effects in hero section  
- Active navbar glow with glass effect  
- Staggered skill badge animations
